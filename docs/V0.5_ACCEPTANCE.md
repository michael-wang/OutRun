## Regression / performance gates

- Core continuous steering strip and 4-detent + neutral soft control unchanged on Pixel 8, PC A/D + Space/Enter intact.
- 1.75× high-speed world pace, bounded shoulder/offroad drag and inward-only recovery, no magnetic centering/no free turn following, audio on/off, pause/menu.
- Phone 20:9 landscape fullscreen/PWA, safe areas, swappable two-thumb, long-press suppression; car-left analog speedometer legible.
- Build, unit tests, all existing Playwright plus new pose and sweep regression; no new fatal page errors. Honest 30/60-step equivalence. **Only claim real Pixel hardware FPS if measured on actual phone**.
- Human finale: does the game feel *at least as fun as v0.4.3*; do the big sweepers feel high-speed and readable; are visually dramatic drifts timed appropriately; does convertible feel like a meaningful quality improvement?
