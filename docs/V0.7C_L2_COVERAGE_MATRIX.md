Each candidate includes a ~30–60 second approach→challenge→exit sampled at nominal 1.75× pace; slower players can take longer. Parameter sets must produce varied human-perceptible driving experiences, not just 16 mathematically different IDs.

### Matrix coverage goals

- Each **C01–C08** occurs exactly twice.
- Every **E01–E06** and every **W01–W04** appears in more than one candidate, including a meaningful four-lane-to-two-lane change and a six-to-eight-lane transition somewhere in rendered scenes.
- Scene visuals coherent: coast/canyon/city art and terrain adapted to actual 3D road geometry, not an independent pasted panorama.
- Intentional difficulty spread: some cruise/easy, some intense/technical, some surprising; **DO NOT automatically forbid hard cases**. Set numerical steering/braking demands through the same v0.7A.1 inverse calibration and record actual machine QA separately.
- If a specific row literally makes an unusable geometry intersection, adjust seed/length/curve radius/grade/roadside clearance to resolve the structural issue **while preserving its C/E/W category coverage**; document substitutions. Avoid a huge speculative player-safety optimizer.
- A two-hairpin switchback may be perfectly legitimate on different heights. Only catch unexpected same-level asphalt overlap, road gaps and scenery intersecting asphalt.

### L2 candidate identity and status

- Every L2 has `id, revision, seed, generatorVersion, C/E/W IDs + concrete parameters + content fingerprint, L3 world, intended vibe, humanVote=UNREVIEWED, humanDifficulty=UNRATED, quick-feedbackEvents=[]`.
- Historical `BRK-01..08 revision 2` remain separately available untouched with their actual KEEP votes. Those approvals do NOT transfer to new L2 candidates.
- For end-of-section human reviews: `KEEP / REWORK / REJECT` + difficulty `1–5` (1 easy, 5 extreme/Godlike) + optional short note + selected praise tags. Feedback/ratings must be user-initiated; tests never fabricate permanent human votes.
- Present four short review batches of four L2 candidates, with Replay, Next, Previous and explicit seed/code. No one-by-one L1 playtest is required.
