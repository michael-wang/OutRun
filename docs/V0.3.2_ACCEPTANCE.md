## Test methodology

- Identical camera FOV/base chase distance, track section, game seed, viewport and starting pose for the A/B. No speed-driven camera trick. If testing an alternate FOV, show it as a separate labeled experiment.
- Measure true **per elapsed second** forward world movement, along-track distance, lateral-road movement, and passing frequencies. Show actual and expected values and explain if near-horizon parallax remains weak.
- When pace increases, re-evaluate corner difficulty and steering authority. If tuning is necessary, do it minimally, don't add automatic lane following or turn perfect by assistance.
- At the outside bounded shoulder, holding outward steering for 15s still does not produce teleport/spin/back-on-road; returning still requires inward player steering and keeps off-road slowdown.
- Check 30/60 fps delta handling, no huge jumps when tab is backgrounded/phone changes apps; devicePixelRatio performance remains acceptable.
- Do not use a new 3D renderer or copy SEGA assets.

## Human GO / NO-GO

For the owner, provide 1.0×, 1.5×, 1.75× and 2.0× on Pixel 8 at the same intended stretch of road. Ask for three judgments:
1. Which one **looks fast** even with the speed indicator hidden?
2. At which one is **cornering still enjoyable** rather than chaotic?
3. Is it good enough to resume development of drifts, track rhythm and convertible?

If none pass, record **NO-GO** for further feature investment and analyze scene perspective/physical scale next.
