## Changes

- Fixed, larger chase composition with aspect-responsive projection, compact top Menu and readable speed. Camera distance/FOV never vary with speed.
- Three visual lanes within the unchanged 14-metre asphalt, denser markings, shoulder paint, near-road reflectors and palms provide visible world motion.
- Launch response increases below 20 m/s. Maximum speed remains 65 m/s (234 km/h); distance and HUD retain real metre/second conversion. Engine/undertone/wind feedback rises with speed, skid remains slip-driven.
- A 4,215-metre route adds repeated S-bends and curved crest/descent. Normal steering remains independent; the v0.2.1 bounded shoulder and touch protections remain intact.
- Real-time integration now substeps elapsed time rather than discarding frame time over 50 ms. Recording and test drivers are external/development-only, not production steering assistance.

Station counts come from world progress, not a claim to count every visible object in the image. Low/mid/high begin at the same route location. Wall time closely matches simulation time. The recordings use real requestAnimationFrame integration with an external digital-input driver, not accelerated simulation. Captures used installed Edge and NVIDIA RTX 5070 Ti hardware rendering at 960×432. The WebM container is 25 fps; measured renderer intervals are about 60 Hz. This is PC evidence, not Pixel FPS. Videos contain no audio.

For braking, `road-challenge.json` records two honest comparisons. A conservative 800 m line exits at 58.19 m/s with no off-road time versus full throttle's 55.18 m/s and 6.4 s off-road, but takes longer (16.1 versus 14.7 s). A more practiced anticipatory steering policy over the same 1,000 m section for each run finishes cleanly with braking in 17.5 s versus 18.0 s at full throttle with 6.6 s off-road. Both exit at 65 m/s. Braking can improve pace; it is not guaranteed to beat every possible full-throttle line.

Capture defaults to installed Edge; `OUTRUN_BROWSER=chromium` selects bundled Chromium. The ffmpeg path is local to this machine; supply the installed Playwright ffmpeg executable elsewhere. Standard browser tests require Playwright's browser installation. Regenerating evidence intentionally changes tracked artifacts.
