# v0.9 public playtest entry

The public entry `/` opens the existing 10-Minute Road Trip with Seed 1.
`/?seed=N` selects another trip; `/?trip=10m&seed=N` remains supported.
Play, Replay same, New Route, Trip Code loading and local reviews remain available.
The Road Trip entry no longer links to development labs or Free Drive.

Explicit historical and developer routes:

- `/?stage=1&seed=1` — Stage 01.
- `/?lab=l2` — L2 Lab.
- `/?lab=pilots` — Pilot Lab.
- `/?lab=bricks` — Brick Lab.
- `/?mode=free` — historical Free Drive.
- Existing `?pace=`, `?velocity`, `?challenge=` and `?stage=` diagnostics retain their route selection; development-only tooling remains development-only.

PWA cache: `coast-drive-v09-public-1`. Existing activation cleanup removes
older `coast-drive-*` caches. Local storage keys and route generation are unchanged.

This release is for `dev` only. Deployment and promotion to `main` await
Michael's explicit PASS. Browser automation is not physical-device testing.
