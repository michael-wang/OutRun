## Focused UI changes

- Gauge position, diameter, safe-area offsets and pointer-events remain unchanged.
- Mobile speed: `clamp(38px,10.2dvh,44px)` -> `clamp(44px,12dvh,50px)`; 915x412 now 49.44px, smallest tested screen 44px. Digital top 50% -> 44%; gear top 29% base / 26% mobile, retaining its size and colors. Desktop digital size 50px -> 58px and top 54% -> 48%. SVG artwork, needle calculations and all six gears unchanged.
- Top center: elapsed driving time and sampled FPS only (`0:33 · 60 FPS`), 16px bold, centered at 50vw and safe top / 16px. Timer uses existing simulation elapsed time. FPS uses the existing one-second frame sampling counter; expensive diagnostics remain DEV + perf opt-in. No additional render loop, timer, dependency or WebGL work. Text only changes when its displayed value changes. FPS shows an em dash until its first sample.
- Route name: existing candidate name (default `10-Minute Road Trip`) at left safe area / 24px, 48px below the top HUD baseline, in 11px text. Free Drive fallback is `Coast Road`.
- Version: `v0.9-r1`, taken directly from existing `TRIP_VERSION`, in 10px text below the route name. This is the existing route release revision, not a fabricated package version or Git SHA. The corner labels are visible during driving and countdown, with pointer-events disabled.
- Full trip code, distance and percentage are hidden in public mode, retained beneath the corner labels in `?qa=1`. QA buttons and all feedback/export/Trip Code functionality remain intact.
