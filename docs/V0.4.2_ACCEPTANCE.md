## Controls / platform regressions

- Default pace 1.75×, no speed-responsive FOV/dolly zoom, 20–25% on-screen car frame width, working original needle speedometer left of car.
- Pixel 8 landscape/fullscreen/PWA, touch-handedness swap, two simultaneous control pointers, scoped long-press protection, safe areas and stable canvas resize.
- No scene-only scrolling or HUD exaggeration; generated 3D road follows actual progression and shoulder behavior.
- Existing npm build/unit/Playwright pass, no fatal JS errors. Audio, Pixel hardware FPS and real touchscreen ergonomics marked UNVERIFIED if only emulated.

## Required paired driving recordings (beyond green unit tests)

- Low/mid/high: equal indicated reference speed, **no steering vs matching quantized notch**. Matching level should substantially reduce cumulative road-relative drift over the interior of a curve.
- Too-fast: equal entry at ref speed, both attempts use full inward correction; **one without slowing should not maintain asphalt**, while coasting/braking at an early, player-achievable point keeps/returns within asphalt for the complete curve.
- Exit: at curve end release steering→neutral; track-relative lateral coordinate remains near constant on the subsequent straight, with no uncommanded yaw/drift tail.
- S-curve: one continuous touchscreen drag (or PC key changes) crosses 0 and steers to opposite side without a residual turn command.
- The normal game must not include a scripted autopilot; automated test-only controller is acceptable and must be clearly identified.
