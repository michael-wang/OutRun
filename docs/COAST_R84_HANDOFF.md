# COAST R8.4：船舶吃水與連續田海

版本 `v0.9-coast-r8.4`。依本次五項修正更新現有海濱旅程，未新增模式，也未改動車輛操控、道路生成或 Ultra-Water 核心。

## 景觀調整

- 船隊由 4 艘增至 14 艘：8 艘帆船、6 艘動力遊艇，分布於約 950–9,500m。每艘沿自己的海岸座標緩慢巡航，沿用原本兩個本地 GLB，共用幾何與貼圖；不跟隨玩家生成或瞬移。
- 加深吃水：帆船船底到平均水面的深度為船長的 15%，遊艇為 7.5%。移除船體自發光、縮小額外搖晃。頂點 shader 直接讀取現有 FFT 位移貼圖，在整艘船的錨點取樣，讓船隨海水升降；沿用水面的位移上限、距離淡化與 mip 選擇，不做 CPU/GPU readback。
- 加入接水暗部、微弱船尾浪花，以及船舶專用的真實太陽深度陰影圖。依追加要求參考 [Ultra-Water floaterShadow.js](https://github.com/Humpalumps/Ultra-Water/blob/6f5a96d6d177f3b4962a044b38477bd58bc2c6f8/src/scene/floaterShadow.js)：正交太陽相機只渲染附近最多 3 艘船，水面以一次硬體 PCF 比較取樣，遮擋夕陽直射亮光，保留船帆／船身輪廓及低角度長影。深度圖手機 512×512、桌機 1024×1024，最多 10Hz；遠處淡出。沒有重畫地形、住宅或植被，也沒有新增光源、後製或水下渲染。改編檔與上游 MIT 授權／版本記錄一併保留。
- 陰影 pass 也取樣原有 FFT，使用玩家鏡頭的波浪 mip 選擇，保持投影與船體升降一致。另有輕微倒影：重用原船幾何，鏡射後投影到水面，隨波紋、距離與高度淡化；這個倒影是局部近似，沒有反射相機或反射 render target。唯一新增的 render target 是上述船舶深度陰影圖，於章節卸載時釋放。
- 主田海仍位於 2,400–3,600m：先稻田後花田，橫向延伸至距道路約 252m。五條寬田帶以約 6m 的田埂／低土坡分隔；平緩田面逐層升高至約 4m 的地形增量，再融回原丘陵。保留原有地表高度取樣，不把作物貼在陡坡上。
- 住宅與夜市之間另有三次農田穿插：稻田 4,500–4,700m、5,900–6,200m、7,400–7,600m；花田 4,700–4,800m、6,200–6,400m、7,600–7,800m。小田區寬至約 148m，其餘住宅、夜市維持原配置。
- 全路段共 91 個獨立田塊、6 個稻草人。稻草人位於各自田塊中央，距道路 76m 或 125m，周圍保留小片裸土；沒有移到路肩，也沒有放大成巨人。

## 效能與資源

沿用 R8.3 的 three-stylized MIT Grass／Wildflowers／GPU wind、CC0 稻株與稻草人，以及既有船舶素材與授權。沒有新增模型下載或第三方依賴。原始來源與授權見 [R8.3 交接](COAST_R83_HANDOFF.md)、`public/assets/coast-farm/`、`public/assets/coast-boats/`。

遠處主要使用田塊色彩、行列地表與低密度草葉；高細節稻株只在第一條近田帶出現。地表增加帶有田塊顏色的低強度環境亮度，避免植物 LOD 淡出後整片變成灰綠草地。中遠田帶保持較低密度，不隨面積同比堆滿高面數模型。每塊田獨立剔除，田面、田埂、小徑、水渠仍合併為一個 draw。

建立植物前，先快取每個 4m 採樣列的地表高度，避免每株重新搜尋原始地形三角形。初始載入預備主農田及第一段小田；後續田塊透過既有 Chunk 工作佇列提前建立，再逐幀預熱材質、貼圖與 instance buffers。固定 seed 與絕對里程維持唯一 Chunk 歸屬；卸載時同步清除預熱記錄，重玩只重建 GPU 資源、沿用已下載 bytes。

## 驗證與試玩

正式建置與目前有效測試套件通過：87 檔、277 項。沿用專案既有四個歷史測試檔的排除設定。覆蓋船舶長時間巡航岸線安全距離、14 艘船／本地模型預算、農田平緩度、唯一 Chunk 歸屬、住宅避讓與田中央稻草人。

凍結相同的正常駕駛鏡頭與水面，對比陰影開／關：512px 手機設定下，3 艘附近船隻參與陰影，海面 1,570 個像素明顯變暗，無 shader 錯誤。記錄與原始對照截圖見 [shadow-ab](evidence/coast-r84/shadow-ab/comparison.json)。測試開關僅存在於 DEV 自動化介面，沒有新增玩家 UI。

110 秒不截圖、從起點出發的高速行駛：陰影加入前／後各 6,598 幀，P95／P99 均約 16.8ms，最長分別 33.3／33.4ms，兩次 ≥50ms 長幀都是 0。初期、中期、後期視窗約 59.93／60／60 FPS，沒有 off-road 或串流錯誤。完整 WebGL draw 計數（含離屏）增加約 1.7–2.0 calls／幀；記憶體多 2 個 texture（同一張陰影 target 的色彩附件及深度附件，512px 約 1.25MiB），幾何數量不增加。記錄：[加入前](evidence/coast-r84/performance/departure/soak.json)、[加入後](evidence/coast-r84/performance/sun-shadow/soak.json)。這是刷新率上限下的 CPU 幀節奏／工作量檢查，不是獨立 GPU 毫秒計時，也不能推算實機耗電或溫度。

全路段農田配置合計 73,402 草葉、45,403 花朵、20,075 稻株 instance（包含近／中 LOD），分散在 91 塊田；不會全部同時送繪。主稻田與花田的主畫面送繪範圍約 196–286 calls；中後段混合住宅與小田的最高取樣約 351 calls。主畫面計數不含陰影與 FFT 離屏 pass，完整幀成本以上述 WebGL soak 為準。

最終完整海濱 → 都市 → 重新開始：8,437 幀，P99 16.8ms、最長 33.3ms，≥50ms 長幀 0；截圖期間排除。第一次準備 5.28 秒，5 個 GLB 各載入一次，重玩沒有重新下載 GLB。農田最多 91 塊，9,100m 後已全數隨 Chunk 退休；都市章節船隻與農田皆為 0。重玩初始窗恢復 67 塊田、4 個稻草人與 14 艘船；後方另外 2 個稻草人隨其田區載入。新陰影圖也正常重建為 512px。記錄：[完整旅程](evidence/coast-r84/final-drive/drive.json)、[摘要](evidence/coast-r84/summary.json)。
