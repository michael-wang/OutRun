# COAST R8.1：遠山地形與依載入時間延長的高速公路

版號 `v0.9-coast-r8.1`。保留已接受的海岸中心線、中景丘陵、植被、度假公路設施、手機 FFT／LOD、操控與遙測。這次包含使用者要求的遠山層次改善，以及海濱後段載入卡頓的流程修正。

## 原因與變更

原流程在海濱終點 **前 4,500m** 就開始建立下一關、編譯 shader 與上傳 GPU 資源，會與海濱繪製同時競爭資源。連接道原本只有固定長度，下一關未就緒時會在終點後約 1,750m 暫停行進。這兩點均不符合「只在高速公路內載入，未完成就繼續開」的設計。

- 改為離開當前景觀、駛入連接高速公路 **260m 後**才啟動下一關載入。海濱自然景觀在 220m 內淡出。
- 等待路段使用三份共用幾何的道路區塊，循環移動位置；邏輯里程持續增加，不重設玩家進度。每段 1,536m，包含緩和 S 彎；區塊移動只在跨段時執行，接地碰撞與可見道路同步更新。
- 下一關道路／景物串流完成、shader 及入場資源預備完成後，選擇前方至少 400m 外的筆直接續點離開。未完成則繼續行駛；不再於固定距離煞停等待。連接點前後道路、虛線與路燈相位相同。
- shader 編譯與 GPU 上傳依物件分幀處理；保留原有串流準備量。預備繪製使用實際 framebuffer 的輸出色彩與裁切 shader 變體，停用清除、色彩寫入及深度寫入，限制為 2×2 區域，再還原 viewport／scissor／材質；避免普通離屏目標的線性色彩版本與正式畫面不同。離開海濱、海面不可見時停止 FFT 更新，讓出 GPU 時間。
- 高速公路使用原本最多 12 輛的 InstancedMesh 車流池持續安排車輛，定期移除已離開範圍的排程、歷史及車道 AI 狀態，不會因等待時間增加而無限累積。

## 遠山

將四列輪廓式山幕改為有完整坡面、起伏山脊與側稜的地形。較低前山銜接既有丘陵，後方山脈保留高度；依坡面法線烘焙日照、谷地深淺與遠方霧色，縮小中景和遠景的材質／造型差距。仍只有兩個遠山 mesh、不到 14,000 個三角形，無新增即時陰影、體積光或後製。

駕駛取景：[轉彎山巒](evidence/coast-r81/views/mobile-7600.png)、[住宅後方山景](evidence/coast-r81/views/mobile-6980.png)、[沿海平原](evidence/coast-r81/views/mobile-1250.png)。完整五點記錄在 `evidence/coast-r81/views/mobile-views.json`。

## 驗證

- 單元測試驗證 100 次道路循環仍連續、切換處前後 390m 為直線、緩彎曲率受限，以及模擬 30 分鐘高速公路車流的固定物件／歷史上限。
- 遠山測試驗證高度、內陸位置、坡面法線與頂點色變化、兩個 mesh 及三角形預算。
- 第一輪桌機 Edge 手機觸控模擬，刻意扣住載入，實際開到海濱終點後 4,501m 才放行，成功駛入都市。等待期間有彎道、可見車流、持續接地，轉場車速不變。海浪計算次數在離開海濱後保持不變。記錄：`evidence/coast-r81/highway/drive.json`。

- 最終建置與既有 CI active suite（排除四個歷史失敗測試檔）通過：85 檔、273 項。
- 最終兩次接續檢查：海濱→都市在海濱終點後 261.9m 開始準備，都市→峽谷同樣在進入連接道後開始。兩次切換保留車速與朝向，沒有頁面／shader 錯誤。強制延遲期間超過原先停車點仍繼續前進。記錄：`evidence/coast-r81/highway-screen-warmup/drive.json`、`canyon.json`；截圖：[等待路段](evidence/coast-r81/highway-screen-warmup/extended-highway.png)、[都市接入口](evidence/coast-r81/highway-screen-warmup/city-arrival.png)。這些功能測試包含中途截圖，長幀紀錄可能受截圖影響；純連續效能另行量測。

- 獨立、不中途截圖的 150 秒連續駕駛完成海濱→都市：8,999 幀，P95／P99 16.8ms、最長 17.0ms，超過 50ms 長幀 0 次，頁面／shader 錯誤 0、取樣 off-road 0。海濱區內預載取樣 0；下一關在終點後約 260m 才開始準備。這次桌機結果顯示原本後段預載競爭及首次顯示預備落差已改善，不能保證手機沒有其他長幀。原始記錄：[continuous-drive.json](evidence/coast-r81/continuous-drive.json)，摘要：[summary.json](evidence/coast-r81/summary.json)。

這是桌機瀏覽器的觸控／畫面尺寸模擬，**不是實體 Pixel 8 效能結果**。實體手機的持續 FPS、長幀感受及遠山景觀仍由使用者驗收。
