## 三個優先改善項目

1. **先讓兩位主角有表情。** 行進時，深髮西裝與金髮白洋裝很容易區分。拉近到圖 05，金髮乘客的眉眼是幾個分離的小點，嘴角幾乎讀不到；兩人的髮束也較順直，少了 B 板上能交代頭部朝向的大弧線。先用乘客做一版：調一條眉弧、一個嘴角與額前兩三束髮，維持頭身比、座位和髮尾的風動。用圖 02 與 05 的構圖驗收。效能風險是逐根透明髮片的重疊繪製，沿用既有髮束網格、頂點色及頭部動畫即可。[角色](../../../src/car.ts) · [髮束](../../../src/hero-groom.ts)
2. **讓 Riviera 的燈具和輪圈在暗面仍有厚度。** 圖 03 的兩條頭燈亮成白片，圖 04 的五輻輪圈像平面色塊；相較之下，圖 01 的擋泥板已有一道能描出曲面的長高光。先把前燈發光面收窄，露出一圈暖暗燈框，再試一組輪圈內外緣的明暗區分。保留燈形、輪徑、鍍鉻飾件和煞車提示。效能風險是每盞燈新增光源、陰影或透明罩；先在現有材質及合批網格內調整，並檢查輪圈高速轉動時的閃爍。[燈具與車漆](../../../src/car.ts) · [輪圈與動態模糊](../../../src/wheels.ts)
3. **讓一般轎車也接得住夕陽。** 圖 06 裡，近處黃色對手的後葉子板反射出暖光，右線白色民車則是兩層直角盒體、深色方窗與平貼尾燈。三者並排時，落差比單看車色更明顯。先做一輛白色民車：讓後窗帶斜度，車頂和肩線各留一小面接光，窗緣與燈框沿用頂點色。用同一位置同框比較，再決定是否擴及其他車型。保留對手原有車漆色系、中距離燈號、滾動車輪和名牌。效能風險是把民車拆成多個玻璃、燈、烤漆 draw call；維持每車型一組實例化網格及現有接地陰影。[民車幾何](../../../src/vehicle-model.ts) · [民車繪製](../../../src/traffic.ts) · [對手材質與輪組](../../../src/rival-view.ts)

## 效能與保留項目

圖 02 的桌面 WebGL 主畫面記錄到 534 次繪製、928,188 個三角形；圖 06 為 567 次、960,192 個三角形。這兩筆是不同構圖的整個場景計數，無法用差值估算單車成本。工作站未偵測到 Pixel 8，手機行進幀時間仍待實機採樣。H1 最適合以圖 06 的車陣重測主畫面與陰影繪製次數，並在手機上比較改動前後幀時間中位數與第 95 百分位。

保留 Riviera 的敞篷比例、左駕、FZR-123、靠門手勢、角色服裝與甩尾姿勢。近處輪胎與路面的關係足以讀出行進方向，中距離的車色、尾燈與名牌可辨識對手。此次交付為正式參考、實拍與美術建議，車輛模型與遊戲程式維持本次拍攝版本。
