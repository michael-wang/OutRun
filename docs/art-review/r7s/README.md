## 本輪實際編修

先閱讀 `scripts/blender/build_r7h.py`：軀幹、手臂、大腿／小腿的少量截面確實是目前形體與衣料的限制。工作從**既有 B-2 全身網格**開始，沒有重跑該生成器，沒有重新建立橢圓截面人體。

- 使用 Blender BMesh 選區細分、局部鬆弛與比例／局部位移編修既有網格。這是腳本執行的網格編修，**不是宣稱完成了人工精雕或完整解剖重拓樸**；臉部與髮型頂點保持原樣。
- 肩頂斜面與上臂連接稍柔化；收整腰側、抬高腰臀位置，增加臀部後側與上胸的局部體積。沒有把整個人物拉高或縮小頭部。
- 調整大腿前側、內膝與膝前形體；提高膝位，將小腿後側體積往上集中，收整腳踝。原本柱狀的腿部剪影有改善，但仍保留較多舊條帶拓樸。
- 縮短過長的上／前臂與手掌、調整手指輕微彎曲。使用原 14 骨的獨立站姿副本，沒有新增通用骨架或改寫遊戲動作。
- 洋裝隨腰臀調整，上提不對稱裙襬，保留側結、裹片與下垂繫帶，增加朝側結聚攏的折線。保留 **B-2：不繞頸、胸前跨肩、後腰接合、下背覆蓋**。
- 重新貼合髖部衣料；放鬆站姿另有一個局部衣料修正 shape key，避免屈膝後大腿穿出裙身。它僅針對這個站姿，**不是五個遊戲動畫均已驗證的服裝解法**。
- 修正前掌鞋底約 9mm 的離地間隙，保留原金色耳環、手環和涼鞋；鞋子外形尚未完成精修。

## 限制與停損判斷

1. 腰臀對比與裙長比原版明確，但髖部仍有截面形成的硬折線，背面裙身尤其明顯。局部細分／平滑未能根本取得核准圖的自然肌群走向與柔和剪裁。
2. 手肘彎折與手掌姿態仍機械化，手指、涼鞋細節不夠細緻；不能把一張較好的 45° 圖當作全角度通過。
3. 面數增加沒有帶來等比例的美感提升。此原型沒有完成適合正式資產的重拓樸，也沒有一般姿態下的完整衣料穿模保證。

因此本輪狀態是**保留正反證據的站姿原型，非美術完工或可整合資產**。在 Julia／使用者判斷前，停止新增變體、人物修型與遊戲同步。
