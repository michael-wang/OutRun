# v0.9 public playtest UI polish

Base: `123a1dc92075f3405eefe9846cdb108472e868e3`. Development branch only; requires Michael's physical-device PASS before promotion.

## Changes

- Mobile gauge center moves toward the car by `clamp(24px, 6vw, 56px)` relative to the steering center, mirrored for swapped controls. At 915x412 this is 54.9px (left edge 36.25 -> 91.14px); at 568x320 it is 34.08px. Existing safe-area offsets remain.
- Gauge diameter remains `clamp(104px, 29dvh, 124px)`, bottom remains safe-bottom + 50px, and steering remains 144x48px with a 2px gap below the gauge. Pointer events remain disabled on the gauge.
- Mobile digital speed increases from 36px to `clamp(38px, 10.2dvh, 44px)` (42.024px at 915x412); top moves 54% -> 50%. KM/H bottom moves 7% -> 3% to provide room. Desktop left moves 32px -> 14vw (still respects safe area), digital speed 44px -> 50px. Artwork, needle and gear are unchanged.
- Touch controls are visible during countdown; the existing playing-only input gate, frozen simulation, input clearing at resume, and blur/visibility safety remain unchanged. Fingers held during countdown require a fresh press after completion, preserving the existing safety behavior.
- `?qa=1` shows Praise, Issue and Camera. Without it, only these QA controls are hidden; the trip HUD, underlying feedback, shortcuts, screenshots and saved data remain intact. Add `&qa=1` to an existing route query.
