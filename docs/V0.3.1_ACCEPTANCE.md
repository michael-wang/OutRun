# v0.3.1 Velocity Gate — acceptance and evidence

All entries require **PASS / FAIL / UNVERIFIED**. **This milestone is not accepted until the human approves the speed feeling**, even if automated tests pass.

## Measurement method

- Compare low and high **settled** car speeds on the **same** track length/segment, camera settings and rendering quality. Use dev-only deterministic controls to avoid user input bias.
- Record elapsed wall-clock time as well as simulation time. Test 30fps and 60fps frame-step equivalence; simulation should not slow proportionally with frame time.
- A speed ratio near ~3:1 (e.g. 80 vs 230 indicated units) should generate a comparable ratio in world travel and roadside pass frequency, allowing sensible easing/dynamics tolerances. If those scales are arbitrary, explain with observed values rather than asserting km/h physically.
- Optionally place regularly spaced posts about **12–18 m** apart *if the game's world-to-meter scale supports this*. At 234km/h (~65m/s) that corresponds to roughly **3.6–5.4 posts/sec per roadside**. This is a calibration reference, not an arbitrary hard requirement where scale differs.
- Do not only add near objects. If **actual world travel** is inconsistent, fix the dynamics first.
- A screenshot does not demonstrate speed. Review a moving clip in the actual browser.

## Preserve all existing platform and game behavior

- Pixel 8 landscape and fullscreen/PWA flows; independently held left/right and gas/brake, reversible layout, Android long-press suppression.
- Fixed chase FOV/distance; no speed-linked zoom.
- Bounded corridor (no open-world travel), penalty outside asphalt, no automatic lane-follow, inward recovery and left/right symmetry.
- No massive asset pipeline, no refactor-only task.

## Human acceptance questions

1. Without seeing the speed readout, does high-speed play **look and feel fast** compared with low-speed?
2. Does roadside and road-marking flow create the *rush* expected from an arcade racer?
3. Does the camera allow a fast driver to read and react to the next bend, without nausea?
4. Is this convincing enough to proceed to drift/track/convertible work, or is it **NO-GO**?
