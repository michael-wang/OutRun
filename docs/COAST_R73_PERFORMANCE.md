# R7.3：Pixel 8 持續掉幀調查

## 實體手機回報與結論範圍

使用者回報 R7.2 在 Pixel 8 海濱開場約 58 FPS，持續行駛接近一分鐘後約 25 FPS；重新整理後開場約 30 FPS，將瀏覽器滑掉再開才回到 50+。這提示持續 GPU 負載、程序／驅動資源壓力或溫度均可能參與，不能直接判定是發熱，也不能僅憑桌機穩定 60 FPS 排除手機問題。本次沒有直接取得 Pixel 8 的 GPU、記憶體或溫度追蹤。

## 程式端可確認的負載

- 手機原先仍使用四層 256² FFT。每次更新包括 1 次頻譜演化、16 次 FFT、4 次輸出組裝；輸出還有 mipmap。每兩個畫面更新一次，在 120Hz 顯示器上可變成 60 次／秒，而非註解所稱固定 30Hz。
- 一般 `renderer.info.render` 在最後場景 render 時重設，未呈現前面 FFT 的所有離屏工作。新的測試攔截 WebGL draw 與 viewport，以計數工作量；這不是 GPU 計時，也不等於螢幕像素數。
- 修改前 100 秒桌機觸控模擬，FFT 約 236 萬離屏 viewport 像素／畫面（約 1.4 億／秒）。場景 draw calls 也隨路段密度改變；不代表效能只取決於植被數量。
- 一般旅程會在距終點 4.5 公里開始預載都市；原本預備場景也完整產生 5 公里景物並預先上傳 GPU。基準測試約 50–60 秒間，已上傳 geometry 數量從約 140–170 增至最高 285，textures 從 36 增至 41–42，與預載吻合。這是有限預載，尚無證據顯示無限洩漏；主執行緒 JS heap 的取樣亦有下降，不是持續單調上升。

## 修正

- 手機海浪改為 128²；所有 GPU target、shader 尺寸、FFT 階段與水面 mip 選擇同步調整。保留四層波長、海岸遮罩、泡沫與夕照 shader；桌機維持 256²。
- 海浪改用時間排程，手機最高約 30Hz，不再由螢幕刷新率決定；慢幀不排入連串補算，傳入模擬的時間仍累計。手機海浪貼圖 anisotropy 設為 1。
- FFT 穩態離屏像素工作量理論降至原本 2/9（減少約 78%），此比例不含主畫面、水面 fragment shader 與其他景物。模擬 render-target 貼圖估算由約 22.7 MiB 降至 5.7 MiB，減少 75%；不含驅動額外配置。
- 手機詳細樹木在批次距離 360m 切到既有遠景模型（原 600m），草、灌木與岩石也縮短高細節範圍。近處配置、樹木大小與丘陵不變。近／遠模型使用相同切換門檻，避免空洞。
- 保留既有旅程預載範圍：試過只預載入口景物，預載上傳時間雖從約 6.5 秒降至 3.5 秒，但轉場後出現一次約 100ms 幀。無法排除是延後載入導致，因此最終版本維持完整預載，先降低持續 GPU 成本，避免改動已接受的轉場行為。

## 重現工具

`node scripts/coast-soak-check.mjs LABEL SECONDS` 從一般旅程入口固定速度駕駛，逐秒保存 draw 計數、離屏 viewport 像素、renderer 資源、heap、植被與章節狀態。預設桌機 Edge、960×432 CSS pixels、DPR 2.75、觸控模擬；應用程式仍套用手機 DPR 上限 1。原始記錄保存在 `docs/evidence/coast-r7/performance/`，舊截圖與記錄保留。

## 最終驗證

- `npm run build` 通過；既有 CI 的 active unit suite 共 84 檔、268 項通過，仍依既有設定排除四個歷史測試檔。本次增加 FFT 尺寸／工作量、30/60/90/120Hz 含抖動時間排程、慢幀不爆量補算與 LOD 切換測試，亦驗證手機批次共用貼圖和釋放。
- 最終 150 秒連續駕駛完成海濱 → 都市，無頁面錯誤、逐秒取樣無 off-road。P95/P99 16.8ms；仍有一次 83.4ms 長幀（都市入口後的取樣秒數約 2.9s、該秒 56 幀），所以不宣稱已消除所有短頓點。
- 同樣前 100 秒，離屏 viewport 工作量從每幀 2,359,690 降至 524,551（下降 77.8%）；可見植被批次估算三角形均值從 131,412 降至 95,853（下降 27.1%，此值不是逐個實例的遮擋／frustum 可見數）。兩版桌機都約 60 FPS，不能據此量化手機 FPS 改善。
- 完成轉場後，最後一筆 texture 數量降到 12、geometry 為 156、植被批次為 0、海面離屏工作量為 0。JS heap 峰值沒有改善（約 118MB → 120MB）；本次減少的是海浪 GPU 貼圖容量與持續繪製量，不宣稱解決了未證實的 JS 洩漏。
- 手機／桌機各八個固定駕駛視角無 console／shader 錯誤；確認 128／256 路徑均可渲染，夕照反光及近處地形植被仍可見。
