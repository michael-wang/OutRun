# COAST R8.5：錯落聚落、晴天鬆餅與海邊休息區

版本 `v0.9-coast-r8.5`，直接更新一般海濱公路旅程。

- 房屋及市集改成小群聚、獨立戶／攤位、前後退縮及輕微轉角，群與群之間留出空隙。市場人群有單人與小團體，站位不再沿固定行列。燈串僅連接同一小群的攤位，依實際彎道路線及燈柱位置接合，不橫跨空地。
- 三個市集共配置 8 個「晴天鬆餅」餐車攤位，重用原先車流中的薄荷綠車體、奶油色棚頂及中英文招牌，加上販售檯、鬆餅托盤與攤商。車輛幾何、招牌幾何與繪圖函式抽到 `vehicle-model.ts`；原有車流沿用完全相同的模型定義，駕駛、交通排程與碰撞程式未改。
- 五個海灣共配置 19 處面向海面的長椅，29 位坐姿大人、28 位附近玩球的小孩；有單人休息、兩人並坐與親子組合。小孩身形較小、手臂及腿部呈玩耍姿態；沿用既有低多邊形人物風格。椅腳及人物依原沙灘高度放置，保持在道路與護欄外的乾燥區域，避開附近遮陽傘。

所有位置由固定路線配方生成，依絕對里程歸屬原有 Chunk，沒有每幀亂數、追著玩家生成或額外場景框架。長椅與人物部件共用既有幾何／材質及 InstancedMesh 批次。餐車車身合併為一份頂點色幾何；招牌共用一張 512×160 本地生成貼圖與材質，隨 StreamedScene 釋放。沒有新增下載素材、動態陰影或後製。原有農田、船舶、夕陽陰影與操控均保留。

## 驗證

正式建置通過。現行測試套件 88 檔、279 項通過，沿用原有四個歷史測試檔的排除設定。新增配置檢查涵蓋：區域邊界、唯一 Chunk 歸屬、不等距群聚、每個市集都有鬆餅車，以及長椅／小孩位於乾燥沙灘與道路外。另比對抽離前後車輛模型函式，幾何定義完全相同。

正常駕駛視角截圖及配置記錄見 [views.json](evidence/coast-r85/views/views.json)；完整高速旅程與重玩記錄見 [drive.json](evidence/coast-r85/final-drive/drive.json)。所有效能測試是**桌機 Edge 觸控／解析度模擬，並非實體 Pixel 8**。

最終高速海濱 → 都市 → 重新開始：8,476 幀，P95／P99 16.8ms、最長 33.4ms、≥50ms 長幀 0，截圖期間排除。沒有 off-road、頁面／shader 錯誤；原有 14 艘船與農田在都市章節皆卸載為 0，重玩恢復初始窗，5 個既有 GLB 各下載一次。招牌不需網路圖片下載，沿用共用本地 CanvasTexture 生成函式。
