# Segment 與 Connector 的最小契約

## 場景在何處結束

Asset Library 保存形狀、材質和姿態，不含全關站號。Scenic Segment 擁有一段局部道路、兩側橫剖面、資產擺放及必要視線。Connector 以相鄰兩段允許的世界擺位、進出 frame 和可用長度作為輸入，承擔兩端之間的地形和道路。Stage Composer 選擇順序、擺位與銜接長度。R0 使用 JSON 範例與一個離線檢查函式，遊戲不載入兩者。

| 欄位群 | 定義 |
|---|---|
| 身分、範圍 | 穩定 id、displayName、localLengthM、coreLocalM。單位為局部站號 m，可有負 s 的視線／物件影響區。每公尺只能由一個路面單元負責 |
| 環境與內容 | environment、assetPackages、requiredSceneLayers，分開登錄真正存在的 package ID 與仍需抽離的程式群組；標明海在左、山在右、海面基準、乾／濕岸條件 |
| Port | 同一中心線的局部 position、heading、signed curvature (1/m)、elevation (m)、grade (dy / 水平弧長)、bank (deg)、lane count / width / profile；左右邊界填地形採樣、水位、岸距，以及缺測欄位。現役五條等寬車道各 3.5 m。改車道時要另附 taper，沒有者記 WARNING |
| Placement | 以世界 Y 為上。局部 right/forward 採 runtime entry frame，平面 forward = (−sin h, cos h)，right = (−cos h, −sin h)，Y 單獨處理。local s 是路程參數，不等於 local forward。放置後比較世界 frame，不可直接比較兩個各自原點為零的 local port |
| 景觀 | 段內保存需要的海側、世界太陽下的相對視線與保護對象。可平移、可嘗試旋轉，重擺後以同站正常追車檢查；不能旋轉全關太陽、任意移動水面或假設沒有遮擋 |

[墾丁實例](kenting-ports.json) 在 track 4850 放局部原點。候選出口 track 6250 的局部位置約為右 59.87、前 1393.91、上 7.00 m，航向相差 +14.00°。入口／出口岸線橫向約 −55／−48 m；各附六個左右地面點。現有路面、海面與塔底都有世界高度約束。這是**核心 port 草案**；第一組傘在入口前 112 m、山體更早生效，實作不能照此兩站裁掉揭景。

## 如何判讀一次銜接

`assessConnector(input, calibration)` 接收放置後的 from（前段出口）、to（後段入口）、可用**水平弧長** availableM、速度情境、選填的預見／煞車距離和逐項人工證據。回傳 status、帶單位的 metrics 和含 area/reason/action 的 diagnostics。校準資料來自實際取樣 CSV，存於 JSON 的 calibration。可重現的三種狀態範例見 [離線測試](../../scripts/route/check-connector.test.mjs)。

- **INCOMPATIBLE**：預算短於兩端水平直線距離；預算只夠直線且不可能匹配端點切線／曲率；同一片海要求兩個不同固定海面；或實測證實接縫、碰撞、地形硬性條件失敗。資料本身無效時函式也會拒算，並用 input 診斷區別。先改擺位、長度或端口。
- **WARNING**：樣本上界提示可能需要較長轉向、坡頂、橫坡過渡或更早煞車；車道改變、固定太陽方位偏離原構圖、視線／落地資料未驗，也都在此列。可在方案紀錄附具名 reviewer、理由、補償和未解風險再試駕，原警告保留。
- **PASS**：必要數學條件合格，候選路面內部與安裝接縫有驗證，而且 alignment、collision、terrain、outlook、drive 五項均有對應證據。範例的直線 fixture 用來展示判定語義。目前沒有新場景組合已通過這套流程。

**候選預警值。** 在整段現役中心線每 5 站號公尺取樣，以實際 XZ 鄰點距離計算變化率，取絕對值的第 95 百分位。它描述「較強於現役大部分樣本」，不是物理極限。尖峰、左右反曲及短於步長的變化需加密驗證。坡頂視距、輪胎落地、場景連通性均不可由統計代驗。

| 量 | P95／現役抽樣最大 | 對可用長度 L 的檢查 |
|---|---|---|
| 水平曲率 | 0.004631／0.008963 m⁻¹ | max(兩端絕對曲率、最短航向差弧度 / L) 是必要的峰值下限。僅 P95 即約 R216 m；不能把一切小於 216 m 的彎判死刑 |
| 曲率變化率 | 0.00007093／0.00037618 m⁻² | 兩端曲率差 / L。端點相同仍可能有劇烈 S 彎，必須查內部 |
| 坡度、坡度變化率 | 3.196%／5.362%；0.0002277／0.00054255 m⁻¹ | 檢查兩端坡度、海拔差 / L 及坡度差 / L；另看坡底緩衝、坡頂視線和車底接觸 |
| 橫坡、橫坡變化率 | 11.06°／13.50°；0.06864／0.15281 °/m | 兩端 bank 及角差 / L；保持實際路面和接觸面的橫坡一致 |
| 車寬與地形 | 現役 17.5 m，五車道；海面 Y −5 | 任一可用車道消失、硬障礙穿入或水線分裂須提供實際幾何判據。兩側不同高程可重新適配時先記 WARNING，已確認無可用重疊面才作硬失敗 |
| 景觀方位 | 既有核心的固定日輪相對前向約 −43.04° 至 −26.04°，負值為玩家左方 | 可在 receiving port 提供 worldSun、min、max 以檢查候選有號方位區間。區間是整段觀察範圍，並非每一個站的新許可誤差。用入口、揭景、泳灣、塔前各自的參照圖檢查落日、水面金光及遮擋 |

**速度與預見時間。** Pace C 的 Windows Chrome 同一段短距離實測，100、200、250 km/h 三組在約 2.00 s 的世界軌跡速度為 27.799、55.546、69.439 m/s。離線以 runtime 的 requiredSteering 計算零橫坡穩態需求；例如 P95 曲率在 200 km/h 約需 0.79，250 km/h 約需 1.08。超過完整轉向輸入屬駕駛 WARNING；橫坡、進場速度、漂移和實際轉向建立時間仍要試。另一次受控水平路煞車 250→99.18 km/h 用 1.108 s、53.58 站號公尺，不含玩家反應。若僅可見 40 m，不能假設該減速可完成。在 200 km/h，100 m 預見空間約給 1.80 s；實測前方車、坡頂或山體會否縮短這段距離。預見距離未知須留待試駕。

## 把可用長度帶進設計會議

| 已存在的範例 | 實際量測 | 對新擺位的意義 |
|---|---|---|
| Tutorial 終端 4350 → Beach 核心 4850 | 水平弦長 474.04 m、中心線平面折線約 500.00 m，端點航向 −7.64° → +39.04°。區間峰值曲率 0.008963，比端點航向差 / 500 的 0.00163 大很多 | 現有形狀包含明顯減速右彎；近 200 km/h 的 500 站號 m 約 9 s。若新址只給 450 m，現端點位置已不可能接。若給 500 m，還要考慮局部轉向峰值、山體和 A6 之後的煞車預告 |
| 核心 6250 → Beach2 override 終點 6800 | 550 **站號公尺**；世界水平弦長 560.86 m，中心線平面折線約 567.67 m | 誤把站號差當世界最大可用長度，會錯判正在運作的道路。R1 要分別記站號長度、物理弧長預算、實際可見距離 |
| 6800 → 外層回接 8450 | 1650 站號公尺、水平折線約 1744.07 m | Harbor 的入口尚未確定，不能將整個既有回接長度當作新 Connector 的空地 |

新的兩端幾何檢查可拒絕明顯不可能的配對，但不能由端點差推導唯一曲線。內部需取樣位置、曲率、坡度、橫坡、車體掃過的空間及兩側地形。審查紀錄要明載採樣間距、遇到的壞站號、可用修正長度與證據。R0 不擬合或產生道路。
