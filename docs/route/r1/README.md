# R1 · 墾丁海水浴場搬移試駕

R1 在獨立本機配置中，將墾丁海水浴場安裝為 A6 之後的第一個大型景點。一般配置仍使用[現役路線](../README.md)。兩者共用 Pace C 1.0×、1.75 的道路設計基準、五車道、固定世界太陽、Y = −5 m 的海平面及七名對手。

## 如何比較

兩個工作目錄可分別執行一般配置與實驗配置。以下為 PowerShell 的搬移版命令，使用現有專案依賴。predev 會準備本配置的岸線與農地資料。

```powershell
$env:VITE_KENTING_INSTALLATION = 'relocated'
npm run dev -- --host 127.0.0.1 --port 5234 --strictPort
```

普通入口可從起跑線完成整場。另可用 `/?at=3800` 從 HUD 3.45 km 試跑 A6、入口、泳灣及出口。HUD 里程等於 track 站號減 350 m。原址比較使用相同程式及 `VITE_KENTING_INSTALLATION=original`。兩個配置分開保存比賽 checkpoint。Option B 沿用專案現有的本機私有素材供應與失敗回退。

## 重現量測

在此工作樹執行以下指令。第一個參數應是獨立的 R0 checkout（`67913f853693ae8a5a83a930d3f07c355ce7f3a8`）。原址模式將完整中心線、地形、岸線及道路界線與 R0 逐站比較。搬移模式另外產生實驗版 CSV、SVG 和接道診斷。SVG 下方包含高程和帶正負號的曲率。

```powershell
node scripts/route/survey-kenting.mjs <R0-checkout> test-results/r1/geometry original
node scripts/route/survey-kenting.mjs <R0-checkout> test-results/r1/geometry relocated
```

100、200、250 km/h 的診斷須同時讀取站號長度、世界水平弧長與實際視距。固定速度的轉向或煞車試驗、靜態地形射線、正常車流下的連續試駕各回答不同問題。播放器、原址比較、兩套地圖、試驗數據和實際畫面放在本機驗證報告。駕駛感與美術交由 Michael 驗收。

## 試駕版量測與已知差異

[全線路線、高程與曲率圖](coast-relocated.svg) · [前後平面疊圖](relocation-plan.svg) · [每 5 m 斷面 CSV](coast-relocated.csv)

原址對照全線 2,841 站。搬移後按局部里程每公尺比較核心，1,401 站的斷面、護欄與碰撞界線相符。實際串流 Worker 的 3,208 個路面斷面，相對頁面取樣的中線最大差 0.51 mm，寬度最大差 0.94 mm。Ultra Water 固定海平面；在 1,528 個沿岸站點，水線內外各 6 m 的乾濕分類一致。重烘焙紋理在連接道與核心的最大水線誤差 0.241 m，陡岩床高插值最大誤差 0.866 m（原址 0.844 m）。

入口與出口的平面弧長分別為 660.65 m 及 1,054.73 m，最大絕對曲率為 0.002491/m 及 0.002177/m。出口最大坡度 4.75%。在 100、200、250 km/h 下，R0 離線檢查在兩段均回報 WARNING。橫坡變化率超過原路第 95 百分位，仍落在原路歷史極值內。正常追車到 track 5270 的近山構圖，200 m 前的低目標可被坡地遮住，原址相應位置也有同樣情形。

**競速事件有一項實質差異。** 在 11 個事故種子中，原址都會在 track 7150 和 7169 生成一組停車故障，候選版均無這組事件。每 25 m 重查整條路，在移位後符合現有 400 m 預警視距及幾何條件的 track 5875–6825，恰好與海灘保護區或警告三角牌前置範圍重疊。候選保留事故安全規則，A4 固定事故、七名對手、流動交通及實際碰撞仍運作。R1 試駕應一併評估這項玩法取捨。

R0 地圖與正式原址版本繼續對應。這三份圖表單獨追蹤 R1 候選，來源提交見圖內註記。港區與防風林的長期位置仍待 R2 決定。
