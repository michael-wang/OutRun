# Grand Canyon Extreme Switchbacks — driving-only experiment

Open `?showcase=canyon&road=lock`. The prior Road Lock is overwritten.
The course is **one-way four lanes**: simple dashed WHITE dividers
and shoulder edges, light asphalt wear. No yellow centerline, cones,
breakdowns or regular traffic in this first playtest.

Three compact 175–185° hairpins: 340–870m, 1430–1970m, 2670–3230m.
The rest is C06/C07 technical multi-reversal driving, INCLUDING the final
two kilometers. No slow straight "connector" scenes. Hairpin banking
targets about 34–36°, with a combined ascending/descending elevation
range of about 310m. Braking should be necessary.

Scenery is intentionally just a few distant placeholder rocks.
Do not repurpose the old Blender GLB on this redesigned road.

Iteration policy: author road, drive, Michael reports, fix only reported
issues. NO proactive geometric safety audits, unit tests or automatic
CI. Existing GitHub Action can be launched manually if an actual
regression calls for investigation. `main` is not changed.
