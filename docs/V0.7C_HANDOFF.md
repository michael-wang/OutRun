## Parameter domain and scope of technical proof

The pure profiles use normalized longitudinal knots and the accepted cosine interpolation. Supported authored inputs have positive length, `0 <= start < end <= 1`, nonnegative curvature effort, direction ±1, positive relative lobe amplitude (C05 unequal to 1), ordered shelf positions inside 0.1–0.9, and positive elevation amplitude. Width endpoints are 2/4/6/8 total lanes: W02 increases, W03 decreases, W04 has a narrower middle. There is no arbitrary runtime profile editor accepting malformed combinations.

The finite/continuity stress suite covers both directions, curvature efforts 0.25 and 1.35, elevation amplitudes 37.5 and 202.5 units, and every supported lane count. Actual rendered compositions use 36/40/44 reference seconds, efforts up to 1.25, elevation amplitudes 90/160, and all 2/4/6/8 lane widths. These ranges are tested examples, not a claim that arbitrary combinations avoid self-intersections. C08's turn window is calibrated to the candidate length for an integrated π heading change. Future parameter sets still require structural road/terrain checks; no difficulty or fun judgement is automated.

The R2 archive is shown as history in the original Brick Lab; it is never copied into or overwritten by browser votes. Feedback storage uses its own `outrun-l2-feedback-v1` namespace and revision/fingerprint key. The portable export includes the current 16 candidates and their current-key reviews; older fingerprint records remain in local storage, but are not silently attached to changed geometry.
