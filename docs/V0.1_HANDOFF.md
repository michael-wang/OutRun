# First Drive v0.1 — local playtest handoff

Date: 2026-10-25 (Asia/Taipei). Repository remote verified as `https://github.com/michael-wang/OutRun.git`. Work is on `codex/first-drive`, based on `1f4ecd88c040ea9b172d2ab1a3f2c3791bafbb62`; implementation is in the local working tree. No merge, push, or public deployment was performed.

## Launch

Windows PowerShell, Node.js 22.12+ and npm (verified with Node 24.21.0):

```powershell
cd C:\astra-dev\outrun
npm install
npm run dev
```

Open **http://127.0.0.1:5173/**. The server is bound to localhost. If another process occupies that port, Vite prints an alternate URL; browser tests require 5173. A fresh copy needs the implementation files and lockfile in this working tree, not only the original base commit. After this work is committed, `npm ci` reproduces the locked dependency installation.

Choose Drive. W/up = accelerator; S/down = brake; A/D or left/right = steering; P/Escape = pause/resume; R = restart. Top-bar buttons provide sound, restart, pause, and Settings. Mobile landscape uses left steering and right gas-over-brake; Settings reverses the groups and persists the choice. Portrait phones show a rotate hint.

## Implemented scope

One approximately 3.78 km looping coastal route, opposing bends and elevation changes, a sculpted original coral coupe, sea/islands, cliffs, palms and pastel villas. Independent accelerator/brake/steering, progressive slip and recovery, shoulder slowdown/bounds, smooth chase camera, synthesized engine and tire squeal. No traffic, score, race, account, music, or backend.

## Remaining limits

- **P1 / human review:** Audio timbre/loudness was not listened to; scenery appeal, speed excitement, drift feel and comfort require a person to play.
- **P1 / unverified hardware:** Mobile is Chromium touch emulation, not a physical phone. Safari/iOS, other GPUs, thermal behavior and actual phone frame pacing are unverified. No FPS claims are made.
- **P2 / intended simplification:** Road-relative steering assistance and bounded shoulders prevent spins; this is an arcade prototype, not free-roaming collision physics. No tire-smoke effect or wheel-spin animation.
- **P2 / build advisory:** Vite reports the approximately 505 kB Three.js-containing bundle above its 500 kB warning threshold; build succeeds. No artificial chunking was added to hide the warning.

Human playtest questions: **Is the scenery appealing? Does speed feel exciting? Is the drift satisfying and controllable?**
