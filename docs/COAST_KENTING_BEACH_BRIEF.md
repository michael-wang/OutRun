# P2-G1 美術提案｜墾丁記憶・南國海水浴場

**狀態：Michael 已授權製作，預定由 Judy 監督 Codex 在 dev 直接整合。**  
**第一個擺放候選：海濱公路 HUD 5,980m、左側海岸，尚非定址。**  
**參考氣氛：墾丁南灣、南國海灘；不複製真實照片或建築。**  
**專案視覺：Style Option B stylized semi-realistic 3D、夕陽暖光、海水 Ultra Water。**

## 這個地方應該讓玩家記得什麼？

長彎後山林逐漸退開，車子從高一點的海邊道路往左望，突然看見**一大片可以真正下水游泳的沙灘**。沙地從奶油金色過渡到濕砂的深琥珀色，淺海明亮透明，再漸變成藍綠深水。成群的彩色陽傘和幾個遊客形成明快色塊；岸邊一座小救生瞭望台／旗幟讓它一眼被認出是海水浴場。遠處綠色岬角與少量海上運動器材收住畫面，夕陽在水上撒出一道金色長路。

**不要把畫面塞滿零件**。玩家以 200–300km/h 前進，應能在一瞬間辨認「有人在戲水的沙灘」，再讀到人群、陽傘、浪花、救生旗等次級細節。也不必把墾丁做成熱帶美國度假村：少量自然樹叢、低矮設施、真實人行通路即可，保持台灣海岸感。

## 首次鏡頭設計

- **揭幕（約 5,650–5,800m）**：前一段濱海防風林離開視野，左側海岸空間打開；遠方先看到大片沙帶、傘群色塊與輕微浪線。
- **英雄瞬間（約 5,900–6,080m）**：沿和緩彎角可見完整沙灘、淺水、人群、救生站與岬角，公路護欄在最靠近道路的一層，保留車道視野。
- **收尾（約 6,100–6,350m）**：傘群往後流逝，海面逐漸回到主角，向 6,580m 「浪打巨石」轉換。範圍可因實際遊戲鏡頭調整；不是硬寫死的物件座標。

## 三層藝術構成

| 距離 | 主題 | 必須避免 |
| --- | --- | --- |
| 前景／路旁 | 護欄與合理的進出步道／緩坡、簡潔路肩 | 陽傘／泳客擋路、看不到海 |
| 中景／主舞台 | **寬沙灘**、多組而非均勻排列的彩色陽傘、救生站、戲水的人形群、衝浪板／租借棚 | 所有傘同樣形狀與間距、平面紙片人、漂浮沙灘 |
| 遠景／水岸 | **沙灘→溼砂→淺水→深海**連續的岸線、動態浪花、樹影綠岬、少量船影 | 突然跳水位、沙地冒出海水、水像平面藍色貼圖 |

**保留夕陽美學**，但不把原始白天參考照片當作遊戲貼圖。使用現有海面、水波、風場與光照；正面優先觀察海水在岸線附近的真實高度與顏色過渡，環視鏡頭也應看到合理的地形。

## 工程與可搬移條件

- 現有編輯資料在 `content/stages/coast/scenic-layout.json`，`heroAnchors.beach-market` = **5,980m**；`direction.json` 標示「海水浴場」與 LEFT。初版可選 `site.heroId="beach-market"`，不直接硬寫 5,980 到船／陽傘／救生台模型。
- 真正可重用元件先放 Asset Library（GLB、可還原源文件）；組件在 `content/scenery/packages.json`，場址只在 Scenic Layout。搬到 5,000m 或 7,000m 不應重畫每把傘；同時要重新**適配**長距離岸線與 Ultra Water 遮罩，不能簡單整片沙灘矩形旋轉。
- 現在公共 `coastBeachHeight`、海平面 `COAST_SEA_LEVEL=-5`、海岸偏移 `COAST_SHORE_OFFSET=-26` 是全局原始地形設定，過窄；局部海水浴場應讓沙帶延展而不改動整關其他岸線。
- 人群要幾組動作和姿態，採 instancing／少量動畫，靠近道路不能穿越護欄。不可因美術改競速、道路、交通 AI 或護欄碰撞。
- 測試 `npm run scenic:build` / `scenic:check`，從實際遊戲追車鏡頭（200–300km/h）觀察揭幕、主景與收尾；Pixel 8 有真機才記 FPS，否則 UNKNOWN。 **實際觀感優先於道具數量或文件長度。**
