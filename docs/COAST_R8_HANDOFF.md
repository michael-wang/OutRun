# COAST-RESORT-R8：海濱平原度假公路

公開版號 `v0.9-coast-r8.0`，場景指紋 `coast-resort-plain-r8-804`。依使用者要求，從「丘陵緊貼路邊」改為左海、近景平原、中景丘陵、右側遠山的駕駛景觀；借用花東景觀的空間層次，不是地理實景重建。

## 景觀與道路

- 道路右側至約 88m 不再隆起丘陵；保留輕微地表坡度，住宅／夜市前庭維持平坦。自然路段以草叢、灌木與大小錯落的樹林為近景。
- ProceduralTerrains 的丘陵主體移至約 150–400m 內陸，樹木與部分灌木同步移到中景，仍依實際地面三角形定位根部。
- 遠山沿固定世界座標配置兩層山脈，最高數百公尺。兩個低面數頂點色 mesh，合計不到 2,500 個三角形，使用遠景深度映射保留山層遮擋順序；不增加手機相機的主場景 far distance、不增加即時陰影或後製。
- 移除海濱紅白交錯路緣、舊高路樁和連續高護欄。改為約 44cm 高水泥塊，穿插約 72cm 高矮護欄，仍位於既有道路邊界外側。兩種設施分別以 InstancedMesh 批次繪製，每個串流區塊共兩個批次。
- 住宅區與夜市附近加入七處斑馬線，位於沿線 750、2700、3930、5410、7010、8460、9740m；附近保留設施開口，斑馬線區段避開車道虛線。這次加入行人穿越的道路標線，未新增行人穿越 AI。

沿用 R7.3 的手機 128² 四層 FFT、30Hz 時間排程、遠距植被 LOD 及共用貼圖。道路中心線、寬度、駕駛物理、控制方式與既有接觸邊界保留。夕陽方向、海灣及海面反光不變。

## 驗收與證據

已檢視八個手機駕駛取景點，以及住宅／夜市三個斑馬線取景點，無頁面或 shader 錯誤。代表畫面：[平原與海景](evidence/coast-r8/final-views/mobile-1250.png)、[轉彎遠山](evidence/coast-r8/final-views/mobile-7600.png)、[住宅斑馬線](evidence/coast-r8/crossings/mobile-720.png)、[夜市斑馬線](evidence/coast-r8/crossings/mobile-3900.png)。

單元檢查涵蓋平原不隆起、中景丘陵高度、植被貼地、近／遠 LOD、手機 FFT 排程、海岸遮罩與原道路幾何一致；新增遠山內陸位置及面數預算、水泥塊／護欄尺寸與道路淨空、七處斑馬線跨越車道及無紅白路緣的驗證。

`npm run build` 通過；依既有 CI 排除四個歷史測試檔的 active suite 共 85 檔、271 項通過。一般入口連續駕駛 150 秒完成海濱 → 都市，無頁面／shader 錯誤，逐秒取樣 off-road 為 0，轉場速度保持。P95/P99 為 16.8ms，仍有一次約 83.3ms 長幀。前 100 秒的每幀 draw 呼叫均值約 253（R7.3 約 261），場景三角形均值約 31.8 萬，與前版相近；海浪仍為 128²／30Hz。原始記錄：[drive.json](evidence/coast-r8/drive.json)，精簡比較：[summary.json](evidence/coast-r8/summary.json)。

測試環境為桌機 Edge 的手機尺寸／觸控模擬。實體 Pixel 8 景觀、持續 FPS 與人工駕駛感受仍待使用者驗收；不以桌機 FPS 代替手機成績。使用同一 AP 的 [本機遊戲](http://192.168.1.106:5180/)，確認右上角 `v0.9-coast-r8.0`。
