# v0.8 — The First Procedural Stage (ALPHA)

**PREPARED NEXT MILESTONE, NOT PERMISSION TO START BEFORE v0.7D.2 IS DELIVERED AND HUMAN-REVIEWED.** Product owner asks for a "procedurally generated, actually FUN first stage" as next objective, after correcting uphill/grip/PC input and finishing in-drive retrospective praise plus skid sound quality. This is ONE polished stage experience — not a giant infinite engine, 16 candidate microtracks, arbitrary money/RPG, or full Level Editor.

## Target player experience

Launch **Stage 01: Pacific Getaway** (original placeholder name). Select a seed or press `New Route`, then enjoy one uninterrupted ~100–150 second nominal real-play journey at the accepted 1.75× arcade pace. The player sees a coherent scenic adventure through supported coast/canyon/city layers with distinct high-speed sweepers, altitude/crest/downhill, occasional genuinely narrower/wider roads, one clearly readable technical corner and a final scenic release/finish. Free driving is fun and responsive even without money or enemies.

Stage duration comes from authored/generated **DISTANCE**, not a timer that spawns road changes. A player who brakes/stops takes longer; don't have the track disappear or jump after 120 seconds. No need for a multi-stage branch fork now.

### Real procedural generation, not three canned pilots simply concatenated

- Use the v0.7D **true distance-localized placements[] L2** and the 18 existing C/E/W primitive shapes. Reuse the 3 human-KEEP L2 pilot *recipes as strong reference motifs*, but compose a multi-act, fresh Stage using a small seeded `StageRecipe` / `JourneyIntent` with a deliberately simple tension→release→challenge→payoff rhythm.
- Stage must contain multiple local L1 placements per L2 beat, with overlap across C/E/W and orderly transitions on the SAME channel. Do not revert to v0.7C's one whole-route C/E/W triple. A long bend can remain a single complex primitive if that's what makes the experience good; do not artificially split just to hit a count.
- Use seeded variation to change **actual driving content**: order of compatible motifs, turning signs, curvature ramp lengths/efforts, hill crest/valley profiles, lane-width rhythm, and placement of scenic reveals. Mere random palm positions/colors or 16 different seed labels does NOT qualify. Seed variation obeys finite parameter envelopes anchored in previously enjoyable driving, not global AAA path/AI solver. Never silently auto-adjust live grip to force a seed to pass.
- Keep a *coherent Stage One identity* (city-to-coast-to-canyon scenic trip or a similar intentional three-act itinerary). Scene transitions use the existing 3 art packs, not new snow/volcano or expensive high-end city world. Vary micro-details/landmarks while holding a sensible thematic arc.
- One generator produces successive L2 beats at distance intervals, reconciles C/E/W values/derivatives (position, heading, grade, width) at seams. Terrain & roadside props follow the actual generated 3D road. Render road ahead in predictable reused geometry/visible chunks instead of generating a massive unbounded world at once. Maintain stable camera road ahead and off-road recovery.
- Use exact approved v0.7D.2 driving/feedback baseline: grade force, speed-dependent lateral curve pressure, warmer/quieter appropriately gated skid audio, all keyboard prompts and actual PS4 Gamepad mapping. DO NOT "fix" procedural hard bends by changing these accepted game rules.

## Versioned route and replay UI

- Normal free drive (`/`) and original Brick Lab / L2 Pilot Lab still work. A simple Stage entry (menu or `?stage=1`) shows **Start Stage**, **Replay Same Route**, **New Route** and a compact visible `Stage Code` (seed + generator revision + car rule profile).
- Two identical Stage Codes reproduce same geometry, stage L2 instance order/placements, background and prop placements under the same version; no unseeded global Math.random for route-critical content. If generator version changes, do not claim code still describes unchanged route.
- End flag/finish screen and satisfactory closure, with optional final KEEP/REWORK/REJECT, 1–5 difficulty, positive/issue highlights attached to **Stage ID/seed and current L2 instance+distance**. No public leaderboards, currency, rewards shop or online persistence. Existing v0.7D.2 RECENT-HISTORY praise workflow must function in Stage One: pressing pad shoulder/keyboard after an exciting event chooses a GENUINE historical 2–3-second-prior snapshot (adjustable), preserving the Stage Code, seed, L2 instance and its actual past world/C/E/W values; export both reactionAt and eventAt. Existing localStorage/export feedback remains compatible; old pilot BRK/L2 human reviews immutable.
- Keyboard-only stage start/focus/Play Again (`P`) and native Enter selection work; gamepad controller flows reuse actual user-approved PS4 layout and v0.7D.2 shoulder/D-pad/Cross praise controls.
- Short first-time controls prompt okay but no new confusing multi-page onboarding.

## First systematic generation proof

- Test **at least five distinct deterministic Stage Codes** for no broken/overlapping same-height road, unrealistic terrain penetrations, no invisible intersections/grade snap and no runaway memory or browser errors; prefer simple retry/reject on obviously broken structural seed, not a complex universal feasibility planner.
- Fully DRIVE at least THREE visibly/motion-distinct Stage seeds in actual desktop browser, inspect screenshots/video and measure duration, curvature/elevation/width and scene transitions. At least two must differ materially in **driver steering/braking pattern**, not only background.
- Human must be able to replay the exact saved seed and get the SAME route. Do not automatically call stage FUN because QA passed — this is for the owner to play and rate several new seeds.
- Keep performance on 844×390/960×432 Pixel-like landscape, and at desktop aspect; actual physical Pixel 8 sustained FPS/audio remains UNVERIFIED unless owner tests it.
- Use stage start speed explicitly (normally 0 with six gear shifts; an optional documented rolling start for test is allowed but not hidden in normal mode); tune driving duration while respecting the new car's acceleration profile.

## Human Stage One gate

**Success:** owner drives Stage One with multiple seeds and says “that felt like a coherent fun procedural first level” and would start another seed, with no monetary incentives. If all seeds feel like the same fixed three pilots, or momentum/audio/UI regress, revise BEFORE attempting a five-minute journey.
