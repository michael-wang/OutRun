## Core v0.6 regressions

- Coherent 1.75× world pace; Arcade Lateral Balance with four soft-detents per side; no auto-follow, rapid on-straight neutral lateral settling; brake-required vs full-gas corners; road-relative off-road bounded slowdown and recovery.
- Three scene acts, smooth visual transitions where relevant; wheels actually roll visibly and front steer, occupants/hair move; no duplicated/protected assets.
- Pixel 8 landscape fullscreen/PWA, independent two-thumb touches, swapped handedness, 15-second GAS long-press without text selection, safe areas and pointer release/blur.
- PC A/D steering, Space accelerator, Enter brake; menu, music/sound toggle, analog left-of-car speed dial, fixed chase camera and stable visual speed cues.
- Preserve normal `/?` or base URL free drive: Brick Lab must be opt-in, not replace the whole game UI.
- Build + unit + Playwright run with actual results and no fatal JS/runtime/asset errors; no whole-road memory spikes on mobile-sized viewport; physical Pixel hardware FPS/vibration/audio unverified unless actually tested.

## Acceptance protocol

1. For EACH BRK-01..08, deterministic static track validation, scripted/no-steer driving comparison and **a real rendered-browser preview**. Inspect low/high and tricky transition segments where relevant. Capture at least one labeled screenshot and motion evidence per candidate; brief combined video is acceptable if clearly segmented.
2. Long enough play/drive/repeat loops (including 120s continuous preview/scene restart across multiple bricks) to catch leaks, scene disposal/road gaps, input state carried between challenges and broken pointer capture.
3. Scripted tests may exercise successful steering/brake sequences, but **no test autopilot may be active in normal game**. Never declare a candidate *fun* solely because a script can pass it.
4. HUMAN GATE: the owner opens Brick Lab on PC/Pixel 8, plays and marks KEEP / REWORK / REJECT, exports reviews. **v0.7A is technically deliverable before owner ratings; v0.7B may not be approved without them.**
