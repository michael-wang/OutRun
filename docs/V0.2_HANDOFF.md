## Exact local launch

Node.js 22.12+ is required; this checkout was tested with Node 24.21.0 on Windows.

```powershell
cd C:\astra-dev\outrun
git switch codex/v0.2-driving-pixel8
npm ci
npm run dev
```

Open **http://127.0.0.1:5173/** and choose Drive. W/up accelerates, S/down brakes, A/D or arrows steer, P/Escape pauses, R restarts. Steering changes heading: use short taps on sweeping bends, lift or brake before sharper corrections, and countersteer to recover a slide. Holding only gas will leave the road. Restart is available after a large departure.

Mobile: left steering and right gas-above-brake; Settings swaps groups and persists the choice. Drive attempts fullscreen on touch devices. Fullscreen retries/exits, pause, restart and sound remain visible. Unavailable/denied APIs show guidance instead of blocking play.

For the Pixel 8 production/PWA route:

```powershell
# In another terminal, with authorized Android Platform Tools and USB debugging:

```

Open **http://127.0.0.1:4173/** on the phone. Try Chrome's Install app option and launch it from the home screen. Keep the preview server and USB mapping running. LAN HTTP is not equivalent to a qualifying loopback PWA origin. Full physical steps are in [PIXEL8_PLAYTEST.md](PIXEL8_PLAYTEST.md).

## What changed

The road-relative model now integrates independent world yaw and velocity heading. Curvature only changes the coordinate reference; it cannot rotate the car's world heading. Lateral motion follows velocity, with no center spring or lateral clamp. Tire response lags body yaw during fast steering, so visible slip affects actual motion and drives skid audio. An oriented 2.26×4.7 footprint triggers progressive off-road drag at the 7-unit asphalt edge.

The chase camera translates with the car at a fixed 10-unit horizontal distance and 4.3-unit height, with a 54-degree FOV. Only heading is smoothed. This avoids both explicit speed zoom and the implicit speed-dependent trailing distance caused by smoothing world position. The car is larger on screen. The route retains its loop and opposing bends, with a pronounced climb, crest and descent. Darker asphalt, richer sea and distinct vegetation increase contrast. Lane dashes are merged into one draw call; touch devices use a capped 1.25 pixel ratio and 512-pixel shadow map.

The production build includes a fullscreen/landscape manifest, original valid 192/512 PNG icons, and a small network-first service worker. Installed display mode is recognized independently from `document.fullscreenElement`. Fullscreen, orientation, resize, visibility and pointer cancellation clear inputs safely. No new dependency, engine, traffic, race, account, or remote runtime asset was introduced.
