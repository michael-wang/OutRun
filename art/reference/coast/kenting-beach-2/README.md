# 墾丁海水浴場 2｜沿山開灣・月牙灣

**沿右山入彎，看見的先是整座灣，再是水裡的人。這一版把沙灘往外海推，讓散步的人穿過兩個傘群之間；另一側的小店與民宿，讓這條公路有了住在附近的人。離開浴場，仍是安靜的海岬和高塔。**

**三張 v0.10.33 真機回饋定位。** HUD 4.3 km（47 km/h、G2，暫停）右側三條線在天空裡折返，轉折處沒有可見支柱；不能從一格圖推斷程式原因。4.7 km 的左前景、近中景大面積空沙，右方只有草地與樹，沒有可辨識店家。4.9 km 近浪有約四個戲水身影，但大部分沙地仍空，右方仍是草地和樹。後兩處電線外觀看來相對平順。第 3 稿針對的是這三處不同的問題，不把有人誤判成沒人，也不假設右邊已有停車場。

## Macro Blockout｜加的是橫向深度，不是賽道長度

- **入口與出口不換戲。** HUD 4.43–4.56 km 以既有右山及路線朝向收住視野，出彎隨正常 chase camera 向左開灣。HUD 4.85–4.95 km 不能再出現左側山塊、平台或被染成沙色的垂直截面。HUD 約 5.43 km 後才逐步抬升尾岬；塔約在 5.67 km。維持固定世界夕陽、路寬、可用車道、路肩與防掉出機制。
- **兩處寬灘，一個主要近泳口。** 寬段先抓 HUD 4.78–4.97 km 和 5.05–5.18 km。固定公路、路緣和乾沙內緣，把**實際地形與海水交線**移往外海，擴大能擺活動的乾沙，而不是改貼圖或把公路向陸側搬。與同樁位的第 2 稿比，兩處代表性橫剖的可用沙帶各以**增加約 20–35 m**為目標；中間讓水線圓滑回進，做出月牙，不做齒狀階梯。從 HUD 4.8–5.15 km 仍是一段連續沙岸。
- **保住近水視窗。** HUD 約 5.27–5.34 km 的水線往路側收回，不要整片海一律外推。理想狀態是：由 K3 看，重要泳客在前方約 45–85 m、落在車前左側，不只是正側方的點。擺位用實際水線作基準：水側約 4–10 m、水深足以切到腰胸或肩；乾沙群不能站到水上。若車速下看不出泳客，先調水口形狀、群組距離與局部明暗，不放大成人形巨物。
- **右側電線有受力依據。** 每一跨從一支實際電桿上的掛點接到下一支電桿的掛點。平面投影是兩端之間的一段直線；側面可以垂墜，但不能水平跟著道路曲線彎。道路轉彎時，在有電桿的地方改方向，不在跨中設隱形節點；遇到沒有可信掛點的末端，就在最後有效支點收線，不硬跨山或跨路。導線如有多條，每條均從各自掛點出發。保留原有路外安全淨距。
- **只替右岸聚落留位置。** 在既有山腳／道路間找得到的乾地安排小型基地；若某位置沒有足夠自然腹地，挪到下一段，不切平整座山。海側沒有新增店屋或第二個遮蔽門，改動不外溢到無關賽段。

**Macro 驗收與通知：** 同樁位記錄 v2／v3 的「可用乾沙內緣→水線」橫向寬度（另記道路中心到水線供定位），至少兩個寬段和一個保留的近泳口；用正常相機連跑確認真水線、進山／開灣與塔的節拍都在。先重訪 HUD 4.3 km，以事發點前、當下及後方約 50 m 的車後畫面跟圖比對；再俯視檢查入口至浴場範圍內每跨導線：所有取樣點在兩端掛點的水平直線上（容許浮點誤差），折角落在有電桿的端點，側視能看出合理垂度。完成這些再通知 Macro 階段結果，並指出未做的真機測試。

**構圖驗收與通知：**
1. 以相同車後鏡頭與常態車速，由 HUD 約 4.25 km（含 4.30 km 電線問題）一直開至 5.70 km，不變 FOV、不用側視／暫停來證明可見。固定截 K1–K4，另補 4.30 km 電線、4.70 km、4.90 km 和原中段空場的前、中、後，使前後版本能對照。
2. 在寬灘代表鏡頭，乾沙遠近至少可讀出兩列活動，重點畫面讀得到三層；從前一群走到下一群之間仍有零星可認的活動。用每約 40–50 m 的連續車後取樣檢查浴場中腹，不應出現連續兩格完全無可認訪客。稀疏段不能修成等距排隊的人形圍籬。
3. 在 K3 前後看得到至少兩個水中人的頭肩被水截住，以及明確在乾地上的人／救生椅；在 K4 前後約 20 m，塔身仍明顯、塔頂有留白、塔腳落在連續岬肩且下一段右彎可讀。
4. 正常駕駛看右側，至少能認出一個低店面、一個退後的住宿量體、兩組建築之間一段開放山景。走外線不穿模，前進時不見跨中折線、飄線、懸空屋或山壁露出房間。
5. 以簡單量體、既有共用造型和配色完成即可，不做正式人模型、招牌、建築材質或資產包。完成後另行通知 Composition，附可實測的版本、截圖／連跑證據與仍需 Michael 判斷的項目，再停在這裡。
